# Match-3：别急着做“关卡很多”，先把 3/4/5 消做成“行为引导”

## 一句话本质

表面上是消除层数差异；实际上核心机制是利用不同层数匹配来构建“维持循环”到“主动思考”再到“情绪反转”的学习曲线；本文重点解释如何通过控制强道具产出时机来引导玩家行为并驱动留存。

流量原因：全民认知、几乎无需教学。真正拉开差距的不是美术，而是 **规则把玩家推向“更优选择”** 的力度。

## 1) 3 消 / 4 消 / 5 消，怎么影响留存？

把它当成一个“学习曲线”：

- **3 消 = 维持循环**：玩家每一步都有反馈，但容易变成“随便点点也能过”。  
- **4 消 = 教你思考**：当 4 消能稳定产出“可见的强道具”，玩家开始学习“我要找更长匹配”。  
- **5 消 = 记忆点**：5 消是短视频最强素材（瞬间清屏/连锁），也是中后期“差一点就能翻盘”的情绪来源。

落地判断：你希望玩家在第几关学会“找更长匹配”？  
通常可以用一个很直白的指标：**每局产生强道具的次数**（4/5 消带来的产出）是否在 20~40 秒内发生 1 次。

## 2) 关卡节奏设计：把“爽点”写进曲线，而不是靠运气

一个易复用的 3 段式（你可以直接当模板用）：

1. **开局 10 步：稳定给糖**  
   - 给 1~2 个“明显可做”的 4 消机会（让玩家复习规则）  
   - 目标进度要肉眼可见（比如第一阶段就完成 25%）
2. **中段：引入阻塞 + 选择**  
   - 让玩家面临“追目标”还是“做更长匹配攒道具”  
   - 阻塞不要堆数量，堆“处理方式差异”（覆盖/锁链/冰块等）
3. **末段：制造 1 次反转**  
   - 要么给一次强道具连锁  
   - 要么把目标剩余压到“只差一步”（差一点的情绪最强）

## 3) 卡点怎么“人为制造”但不让人骂？

你想要的不是“卡死”，而是“差一点”：

- **失败原因可解释**：玩家能说出“我如果早点做那个 4 消就好了”  
- **补牌可控随机**：对掉落做软约束（例如：避免连续 5 次不给可用步）  
- **破局手段明确**：要么强道具组合能解，要么给 1 个轻提示/开局道具

## 4) 一次交换到底如何结算？

三消最容易出现“演示时能跑，上线后规则不可信”的问题。原因通常不是动画，而是结算顺序没有固定。一次玩家交换应当遵循同一条契约：

1. 只允许交换相邻格；交换后只扫描两个交换格所在的横线与竖线。
2. 如果没有任何匹配，立即回滚到原棋盘，不能让无效交换悄悄改变掉落结果。
3. 收集本轮所有横向与纵向匹配，再合并交叉格；扫描阶段不直接删除格子。
4. 根据匹配长度与形状确定特殊块生成位置，再批量清除普通块、阻挡和被触发的特殊块。
5. 每列从底部压实空格，再从顶部补齐新块；补齐后继续扫描下一轮连锁。
6. 棋盘稳定后检查是否还有合法交换；没有时只重洗普通块，并验证重洗后没有自动消除且至少有一手可走。

```ts
function resolveSwap(board: Board, swap: Swap) {
   if (!isAdjacent(swap) || !swap(board)) return { accepted: false };

   let matches = findMatchesNear(board, swap.a, swap.b);
   if (matches.cells.size === 0) {
      swap(board); // 无效交换必须回滚
      return { accepted: false };
   }

   const rounds: ResolveRound[] = [];
   while (matches.cells.size > 0) {
      const round = buildResolveRound(board, matches);
      applyResolveRound(board, round);
      applyGravity(board);
      refillWithoutImmediateMatch(board);
      rounds.push(round);
      matches = findAllMatches(board);
   }

   if (!hasLegalMove(board)) reshuffleConstrained(board);
   return { accepted: true, rounds };
}
```

这段骨架的重点不是 API 命名，而是把“扫描、决定、修改棋盘”拆开。否则 L/T 形、交叉匹配和多个同时发生的特殊块会依赖数组遍历顺序，同一输入可能得到不同结果。

## 5) 最小可验证（MVP）怎么测？

用同一张关卡，只改一件事：

- A：4 消不产道具 / 5 消才产  
- B：4 消产道具 / 5 消更强  

先用同一初始棋盘和同一随机种子做对照；每次只改一件事，避免把补牌差异误判为规则效果。

除了 `首局时长`、`第 N 关流失点`、`道具使用率` 等结果，还要记录玩法本身是否成立：

- `合法步数量`：稳定棋盘是否始终有可走步，且不只剩唯一答案；
- `无效交换率`：玩家是否理解交换限制，还是预览/反馈不够清楚；
- `平均连锁深度`：连锁是偶尔的高潮，还是频繁自动完成并稀释决策；
- `4/5 消触发率`：强道具是否在玩家学得会的节奏内出现；
- `死局率与重洗次数`：随机补牌是在制造选择，还是在制造无解；
- `目标推进率`：高分操作是否真的帮助完成关卡，而不是只制造华丽动画。

如果 4 消奖励看起来很大，但玩家始终用普通 3 消过关，先检查关卡目标和棋盘准备路径；如果玩家失败时已经没有合法步，先修补牌与重洗，再讨论“难度”。

## 边界条件

- 需要处理玩家因只进行 3 消而陷入“随便点点也能过”的无效循环状态。
- 需要处理 4 消或 5 消发生时特殊块的生成位置、形状和触发优先级；同一局面必须可复现，不能依赖扫描顺序。
- 需要处理中段关卡中玩家面临“追目标”与“做更长匹配”两种策略时的选择分支。
- 需要处理末段反转时，是给予强道具连锁还是将目标剩余压至“只差一步”的状态。
- 需要处理失败原因是否具备可解释性，以及补牌软约束能否通过随机种子、日志和回放被验证。

## 设计取舍

- **收益**：4 消能稳定产出可见能力，让玩家学会寻找更长匹配；5 消成为稀有但可理解的翻盘时刻。
- **代价**：若特殊块或连锁奖励压过关卡目标，玩家会追逐随机动画；若普通 3 消已足够过关，学习曲线同样失效。
- **替代**：不要只靠增加颜色、障碍或步数制造难度。先固定结算顺序、保证合法步、记录单变量实验，再用开局教学、中段分支、末段回收组织节奏。

一句话总结：**Match-3 的留存不是关卡数量堆出来的，是 3/4/5 消把玩家“训练”出来的。**
