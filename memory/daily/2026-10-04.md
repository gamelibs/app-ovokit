> 执行：Kimi Code CLI（路由/内容层主 Agent + 4 个翻译子 Agent）

## 一、区域自动识别（localeDetection 开启）

- `src/i18n/routing.ts`：locales 扩为 `zh-CN/en/ja/ko/es/pt`（zh 无前缀，其余 /en /ja /ko /es /pt），`localeDetection: true`——首访按浏览器 Accept-Language 307 跳对应前缀并写 `NEXT_LOCALE` Cookie；`localeCookie.maxAge=1 年`（默认会话级 Cookie 关浏览器即失效，已修）
- 实测：ja → 307→/ja；pt-BR → 307→/pt；zh-CN → 200 不跳；带 Cookie 二次访问（无 Accept-Language）→ 自动落 /ja 渲染日语 ✓
- 语言切换器扩 6 语言标签（中/EN/日/한/ES/PT），手动切换与 Cookie 记忆兼容

## 二、内容层多语言回退链

5 处 locale→目录映射泛化（plays/archetypes/patterns/features/implementation-traits 的 spec loader）：`localeCandidates`——zh-CN 读自有；en→en→zh；ja/ko/es/pt→自有→en→zh，命中非请求语言标 `untranslated`（页面显示对应语言的「暂未翻译」提示）。实测 /ja/play/match-3 回退英文内容 + 日语提示 ✓
